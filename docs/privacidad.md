# Privacidad de esta publicación

La publicación se prepara desde una carpeta aislada y una lista explícita de archivos de documentación. No se publica la carpeta de trabajo completa.

## Exclusiones

- Archivos de voz, imágenes, video, referencias faciales y resultados de usuarios.
- Nombres personales, rutas absolutas de equipos, ubicaciones, nombres de instituciones y conversaciones privadas.
- Credenciales, tokens, archivos de entorno, registros, identificadores de procesos y volcados de diagnóstico.
- Modelos, instaladores, cachés, dependencias y materiales de terceros.

La documentación usa ejemplos inventados y rutas relativas. Los datos técnicos generales describen un perfil de capacidad, sin información identificativa del equipo.

Antes de cada publicación se inspeccionan los archivos preparados, se buscan patrones de secretos y datos personales y se revisa la lista que Git enviará. Este procedimiento reduce el riesgo de publicación accidental; no sustituye revisar el contenido.
